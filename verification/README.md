# Finite mathematical checks

Run from the repository root:

```bash
python3 -m pip install -r verification/requirements.txt
python3 verification/run_all.py
```

The suite prints a concise pass summary and writes no files by default. To retain
the numerical observations in machine-readable form:

```bash
python3 verification/run_all.py --json verification/report.json
```

The separate [repository structure check](check_repository.py) verifies the
selected learning route and local navigation:

```bash
python3 verification/check_repository.py --json verification/structure_report.json
```

It checks exactly M01–M30, this project's 14/16 phase allocation, resolvable earlier
prerequisites and absence of dependency cycles, one selected Childs source dated
17 April 2025, local file/heading targets, and reachability of reader pages from
the root README. It also performs a bounded scan for private coaching/process
paths and checkpoint markers. The report hashes the Markdown files it inspected.
External links receive syntax checks only. Scientific qualifier agreement,
explanatory quality, public/private meaning and source suitability require manual
review; local structure does not certify those judgments or hosted mathematics.

All graph instances, port permutations, perturbations and test parameters are
deterministic. The only dependency is NumPy. The checked environment used
Python 3.12.14 and NumPy 2.3.5; the report records the actual NumPy version of a run.
Floating-point identities use an absolute tolerance of `3e-10`. Incidence and
matrix-tree determinants are evaluated separately by exact integer
fraction-free elimination.

The endpoint-output theorem assumes sorted rotation ports (neighbors in increasing
label order) or sorted adjacency access. The deliberately permuted-port matrices
below test the stronger **algebraic** identities for projected encoding and arc
folding. They do not test efficient clean conversion to endpoint-pair output from
arbitrary port orders. The dense test code can inspect its entire explicit graph;
that convenience is not an algorithmic access assumption.

## What the checks establish on the tested instances

| Check | Scope and independent comparison |
|---|---|
| Actual projected-unitary encoding | Explicit control-Hadamard, controlled rotation-map and known coin matrices are multiplied. Their projected block is compared with `(V-RV)/2`, and the whole matrix is checked unitary. Local port orders are permuted deterministically to test these identities; this does not test endpoint erasure. |
| Degree normalization and gap | Eight connected regular graphs, from degree one through degree five, test `A* A=L/(2d)`, the known uniform null vector, and singular gap `sqrt(gamma/2)`. This checks the advertised absence of an extra square-root-degree normalization charge. |
| Matrix-tree amplitudes | Every maximal minor is enumerated on K2, C3, K4, C5, K3,3, the cube, K5 and K6. Graph connectivity/cycle tests, exact reduced-incidence determinants, exact Laplacian tree counts and floating polar minors are compared. Non-tree minors must vanish; tree amplitudes must have equal magnitude and only the predicted determinant sign. |
| Sign computation | All 1,441 labelled trees with two through six vertices are generated by Prüfer sequences. Rows are reordered and reoriented. A literal Euler traversal and a separate BFS are compared with sorting-based pointer-doubling joins; a fixed bitonic comparator schedule computes parity. The final sign is checked against an exact determinant. Repeated query keys at the absorbing terminal are exercised. |
| End-to-end state | K4, C5 and K3,3 are simulated as full ordered-particle tensors: antisymmetric orbital labels, independent Fourier transforms, and polar/fold maps. Sorting with permutation parity produces a tree-independent uniform permutation resource; its inverse is applied explicitly. The remaining state must be the positive uniform superposition of sorted **canonical-arc subsets** representing spanning trees, up to one global phase. Endpoint interpretation uses the explicit test graph and does not certify conversion cost. |
| Approximation and leakage | An explicitly bounded odd test polynomial separates good-block error from full dilation-state error. It is a finite illustrative polynomial, **not** the asymptotically optimal QSVT compiler. Independent small edge-space unitary perturbations create non-tree leakage; sign correction preserves the state error and cannot remove that leakage. |
| Promise boundaries | A four-vertex star is rejected as irregular. A locally normalized coin on that graph has the degree-weighted null vector rather than the uniform one. Two disconnected triangles have rank `n-2`, demonstrating why connectivity is required. |
| Hidden-bit lower-bound gadgets | K4 and cube bases receive every cubic bridge gadget. Three label-bit patterns are tested per base. Degrees, connectivity, the tenfold vertex blowup, forced bridges and bit decoding are checked. Relabeling preserves the gap, which is compared with the written conservative lower bound. |

The end-to-end simulation acts on the mathematical isometries and permutation
resource. It does not synthesize the optimal-degree QSVT angles or every reversible
bit operation. In particular, it does not measure physical gate counts, routing,
fault-tolerant overhead or device runtime. The pointer-join implementation checks
the combinatorial computation, rather than compiling its complete reversible
sorting-network circuit.

The finite gadget gaps do not establish an infinite expander-family gap or a
quantum query lower bound. The written arguments in `science/` establish those
claims. Similarly, successful finite determinants and state simulations support
the conventions and load-bearing identities without proving arbitrary-size
correctness, novelty, journal significance or release readiness.

## Actual-host mathematics

The read-only `Hosted mathematics` workflow runs an anonymous Chromium context against exact commit-pinned public GitHub pages. `verification/hosted/config.json` selects a representative probe or the final all-Markdown capture. The collector inventories the pinned Git objects, compares accessible MathML structure and symbols with the source at widths 1440 and 760, and retains screenshots and machine-readable evidence as CI artifacts. The final report also requires human visual/source review; a probe or a local TeX compilation cannot establish complete hosted correctness.

The browser dependencies are isolated from the scientific Python environment: Playwright 1.56.1 and MathJax 3.2.1. The generic collector, probe and checker are pinned together by their source hashes. They do not sign in, inject replacement mathematics into GitHub, change repository settings, or alter scientific content. CI artifacts expire; the final preservation record retains the important findings and exact source binding separately.
